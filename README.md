# Compressing Collections of Trees with Decision Equivalence

This repository hosts code to replicate the experiments in the NeurIPS 2026 paper *Compressing Collections of Trees with Decision Equivalence*.
Code is partly based on the codebase for the ICML 2025 paper [Leveraging Predictive Equivalence in Decision Trees](https://arxiv.org/abs/2506.14143).

## Environment
To use the environment specified in `requirements.txt`, run the following commands with python3.10:
- `python3.10 -m venv .venv`: this creates a virtual environment
- `source .venv/bin/activate`: this activates the virtual environment
- `pip install -r requirements.txt`: run this from the base of the repository
Before running any slurm script, make sure to activate your environment.

The AdaBoost experiments (Tables 2–4) also need `pystreed`, built from a modified STreeD that supports conservative
partitions (a feature value of `-1` means missing). A patch file is included, and can be installed (with virtual environment active)
by running

  ```bash
  git clone https://github.com/AlgTUDelft/pystreed.git
  cd pystreed
  git checkout c059f87 # the commit we used for our experiments; though later commits are unlikely to break functionality
  git apply ../streed_missing_values.patch   # or: patch -p1 < .../streed_missing_values.patch
  pip install . # builds the C++ extension, so it needs a C++ compiler and CMake.
  ```

Code is written in Python module form.
Run files, e.g. `preprocessing/binarize.py`, with
`python -m preprocessing.binarize`.
Note the lack of a ".py" at the end.
All unit tests can be run by calling
`python -m pytest tests`.

## Replication Guide

### General Structure

Experiments are written to run on a slurm batching system. They are launched from the base of the repository
using the scripts in the `slurm_scripts` directory with the command `sbatch slurm_scripts/<target_script>`.

To run our experiments on a non-slurm system, run the python calls in the slurm script with
the index arguments from the script's `#SBATCH --array=...` line.

The `netherlands` dataset is not included as this dataset is not fully open access.

### Replicating Specific Results

- Figure 1's experiment data is generated using `slurm_scripts/time_hashing.sh`,
and is plotted with `python -m experiments.plot_hashing` from the repository root directory. These scripts have high timeout and memory limits, as they are baselining some computationally intensive alternative approaches.

- Table 1's experiment data comes from `slurm_scripts/rset_count.slurm`,
and is aggregated using `get_sizes.py` from inside `experiments/counting_results/rset_count/`.

- Tables 2 and 3 come from `slurm_scripts/compress_ada.slurm`, and Table 4 from `slurm_scripts/tune_ada.slurm`.
All three tables are generated by running `_plot_compression_time.py` from inside `experiments/ada_results/`; this script generates ada_compression_stats_table_depth_3.tex, ada_compression_time_table_depth_3.tex, and baseline_stats_table.tex in the same folder. These contain the data for tables 2, 3, and 4 respectively. The AdaBoost results are slightly sensitive to particular choices of cpu hardware (i.e. access to AVX-512 can affect the exact trees learned throughout the boosting procedure). The tables in the paper were run on nodes without AVX-512 (the setting for the nodes in our department cluster that were most accessible for timing experiments).
